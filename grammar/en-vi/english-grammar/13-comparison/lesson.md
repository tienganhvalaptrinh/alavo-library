# So sánh hơn, so sánh nhất và các cấu trúc so sánh (A1–C1)

Bài này đang được soạn.

## Phạm vi dự kiến theo cấp

### A1

- Dạng so sánh nhất đơn giản như best (my best friend)

### A2

- So sánh hơn: -er, -ier, gấp đôi phụ âm, -r, bất quy tắc, more + adj, than (bigger than, more difficult than)
- So sánh nhất: the -est/-st, the most, in/of + noun, my best friend (the tallest in the class)
- Cấu trúc be like + danh từ/đại từ (She is like her mother)
- the + so sánh nhất (the best, the most expensive)

### B1

- Lặp so sánh hơn với and (It's getting colder and colder)
- So sánh hơn có từ bổ nghĩa (so) much, a bit, even, and (much better, even worse)
- So sánh nhất: one of the + so sánh nhất, the best + N + present perfect/to V (the best film I have seen)
- Sau than: mệnh đề đủ và rút gọn; as ... as; rather than; the same as; like/similar to (taller than I am, the same as mine)

### B2

- So sánh hơn với a lot, much + danh từ, slightly (a lot taller; much more money; slightly cheaper)
- So sánh nhất với by far; lược 'the'; the + so sánh nhất + danh từ + to V (by far the best; the first person to arrive)
- Cụm trạng từ so sánh (more carefully than before; as quickly as possible)
- So sánh hơn + than + mệnh đề không chia; the same as + mệnh đề; rather than + V (cheaper than to rent it; the same as I did)
- Cấu trúc so sánh kép the more ... the more ... (The more you practise, the better you get)

### C1

- So sánh nhất + danh từ + hậu bổ nghĩa (the best film I have ever seen; the most helpful person you could meet)
- Trạng từ mức độ bổ nghĩa so sánh hơn (considerably bigger, slightly more carefully)
- Trạng từ so sánh nhất 'best' + mệnh đề (what I like best is when…; I work best when it is quiet)
