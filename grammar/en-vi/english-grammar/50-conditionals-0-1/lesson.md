# Câu điều kiện loại 0 và 1 (A2–C1)

Bài này đang được soạn.

## Phạm vi dự kiến theo cấp

### A2

- If + hiện tại đơn, hiện tại đơn/mệnh lệnh; điều kiện có thật (If you heat ice, it melts; If you need help, call me)
- Mệnh đề if chỉ điều kiện (If it rains, we'll stay home)
- will trong mệnh đề chính sau if (If you hurry, you will catch the bus)
- Hiện tại đơn sau if cho tình huống thật (If she comes, we start)

### B1

- Loại 1: if + hiện tại đơn + will/modal; if + hiện tại tiếp diễn; unless (If it rains, I will stay home)

### B2

- Liên từ phụ thuộc chỉ điều kiện: if, unless, as long as, provided (that) (unless you hurry; as long as you call)

### C1

- If + should: lịch sự, trang trọng (If you should need help, please call)
- Mệnh lệnh + and mang nghĩa điều kiện (Work hard and you will succeed)
- should sau if (If you should see her, …)
