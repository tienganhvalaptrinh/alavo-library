# Câu điều kiện loại 2, 3 và hỗn hợp (A2–C2)

Bài này đang được soạn.

## Phạm vi dự kiến theo cấp

### A2

- would trong tình huống tưởng tượng (I would buy a house if I were rich)

### B1

- Loại 2: if + quá khứ đơn + would/could; If I were you; loại 3: if + quá khứ hoàn thành + would have V3
- would trong tình huống tưởng tượng quá khứ (would have V3)
- Quá khứ hoàn thành sau if (If I had known)
- Quá khứ đơn sau if cho tình huống tưởng tượng (If I won the lottery)

### C1

- If + quá khứ hoàn thành + modal, tình huống tưởng tượng và hối tiếc (If I had known, I would have told you)

### C2

- Điều kiện và giả định trong văn phong trang trọng (đề xuất, chưa có nguồn EGP)
